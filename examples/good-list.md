# Machine learning reading list

A curated list of learning resources, kept alphabetically.

## Courses

- [Fast.ai Practical Deep Learning](https://course.fast.ai) — free, code-first course for practitioners.
- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) — short modules with exercises.
- [Stanford CS229](https://cs229.stanford.edu) — the classic mathematical foundations course.

## Books

- [Deep Learning](https://www.deeplearningbook.org) — Goodfellow, Bengio and Courville, available online.
- [Hands-On Machine Learning](https://www.oreilly.com/library/view/hands-on-machine-learning/9781098125974/) — practical scikit-learn and TensorFlow guide.
- [Pattern Recognition and Machine Learning](https://www.microsoft.com/en-us/research/publication/pattern-recognition-machine-learning/) — Bishop's reference text.

## Tools

- [Jupyter](https://jupyter.org) — notebooks for exploration and teaching.
- [scikit-learn](https://scikit-learn.org) — classical algorithms with a consistent API.
- [Weights & Biases](https://wandb.ai) — experiment tracking and reporting.
